## Лабораторна робота №2
N = 16, K = 1, a = 1, b = 0, c = 1

## Опис методів
- **Завдання 1 (`Task1_Aggregate`)**: за один прохід шукає суму, середнє, мін/макс з індексами та кількість нулів.
- **Завдання 2 (`Task2_Filter`)**: створює масив точного розміру для елементів, кратних 3.
- **Завдання 3 (`Task3_LongestSeries`)**: знаходить найдовшу підпослідовність однакових чисел підряд (з урахуванням останнього елемента).
- **Завдання 4 (`Task4_ShiftLeft`)**: циклічно зсуває масив вліво на 1 елемент без виділення додаткового масиву.
- **Завдання 5 (`Task5_Matrix`)**: обробляє матрицю 4x5, виводить суми рядків, максимуми стовпців та номер рядка з найбільшою сумою.

# Лабораторна робота №3

N = 16, K = 1, a = 1, b = 0, c = 1

## Базові випадки рекурсивних функцій
- **Завдання 1 (`GetTotalFileSize`)**: Базовим випадком є папка, яка не містить підпапок (цикл обходу підпапок завершується без рекурсивних викликів).
- **Завдання 2 (`CountGreaterThanOne`)**: Базовим випадком є підмасив з одного елемента (`lo == hi`), де повертається `1`, якщо елемент більший за 1, інакше `0`.
- **Завдання 3 (`FindSubsets`)**: Базовим випадком є досягнення цільової суми (`targetSum == 0`) або вихід за межі масиву / перевищення суми (`index >= arr.Length || targetSum < 0`).
