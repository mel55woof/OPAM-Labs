### Завдання 6 · Висновки
1. **Відношення порівнянь на $n = 10\,000$:** відрізняється від теоретичних оцінок через наявність великої кількості однакових елементів (діапазон $[0; 20]$), що зменшує кількість інверсій.
2. **Чому `Array.Sort` швидший:** використовує високоефективний гібридний алгоритм (IntroSort), оптимізований на рівні машинного коду .NET з мінімізацією промахів кешу процесора.
3. **Вибір алгоритму (100 тис. записів, ключ 0–300, стабільність):** Найкращим вибором є **сортування підрахунком (Counting Sort)** або **сортування злиттям**, оскільки малий діапазон ключів дозволяє сортувати за лінійний час $O(n + k)$ із збереженням стабільності порядку.
